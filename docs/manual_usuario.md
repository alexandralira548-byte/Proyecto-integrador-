# MANUAL DE USUARIO

SISTEMA DE REPORTE DE FALLAS DE COMPUTADORAS DE LABORATORIO

1. INTRODUCCION

Este manual explica el funcionamiento del prototipo del Sistema de Reporte de Fallas de Computadoras de Laboratorio. Su objetivo es orientar 
al usuario durante el recorrido por las diferentes pantallas y funciones del sistema.

2. ACCESO AL SISTEMA

Al ingresar al prototipo, se muestra la pantalla de acceso. El usuario puede introducir sus credenciales
y seleccionar la opción de ingresar para llegar al tablero principal.

3. TABLERO PRINCIPAL

En el tablero se presentan las opciones principales del sistema, desde donde se puede acceder al registro
de reportes, consultar fallas y revisar su seguimiento.

4. REGISTRAR UNA FALLA

Para registrar una falla, el usuario debe:

- Ingresar a la opción Reportar una falla.
- Seleccionar el equipo correspondiente.
- Revisar la información del laboratorio.
- Seleccionar la categoría de la falla.
- Escribir una descripción del problema.
- Presionar el botón Enviar reporte.

Al finalizar, el prototipo muestra una confirmación del registro y el número del reporte.

5. CONSULTAR SEGUIMIENTO

El usuario puede seleccionar la opción Ver seguimiento para revisar el historial de un reporte y conocer los avances registrados.

6. REGISTRAR SOLUCION

El personal de mantenimiento puede ingresar a la opción Registrar solución, escribir la descripción de la solución y el tiempo empleado en horas, y guardar la información.

7. CONSULTAR REPORTES

En esta sección se pueden consultar los reportes registrados, aplicar filtros y revisar los detalles de cada uno. También se puede limpiar la búsqueda para volver a mostrar la lista.

8. ESTADOS Y VALIDACIONES

El sistema contempla diferentes estados para identificar el avance de los reportes, como Pendiente, En proceso y Resuelto. El prototipo también presenta 
mensajes de validación para campos obligatorios y credenciales incorrectas.

9. CONCLUSION

El prototipo permite visualizar el proceso de registro, consulta y seguimiento de las fallas de los equipos de laboratorio, facilitando la comprensión del funcionamiento general del sistema.
